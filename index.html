《好食光》AI 健康饮食 App

以「精细记录 → 精准估算 + 体型诊断」为核心的 AI 健康饮食产品：反「体重焦虑」，不做大而全的卡路里工具，而是把「记录工具」升级成「诊断工具」。

🍽️ 打开 App 在线体验 📄 查看 PRD
详情▾
痛点 ①

市面 App 按「食物名 + 分量」估算热量，中式家常菜做法差异大，同一种菜热量可差一倍，估算严重失真。

痛点 ②

减脂只看体重数字，体重不动就焦虑，忽视了围度下降、体型变好这些真实正向反馈。

痛点 ③

记录工具只给数据、不给分析，用户不知道「自己差在哪、该怎么调整」。

我的工作流
用户调研 → 亲测竞品与用户访谈 方案设计 → PRD 与高保真原型 开发上线 → 独立实现并部署 数据迭代 → 反馈驱动 20+ 轮优化
关键产品决策
① 用「记录颗粒度」换「估算精准度」

设计烹饪方式、用油量、酱料、自制/外卖四个精细字段，由 AI 按做法动态校准热量；同时支持拍照识别营养成分表 + 手动克重，让每餐估算有据可依。

② 反「体重焦虑」的指标观

把多部位围度变化放在首页第一指标位、体重降权；支持 11 项围度 + BMI + 腰臀比 → AI 体型画像（梨形 / 苹果型 / 沙漏型等），并按体型给出饮食侧重建议。

③ 从记录工具升级为诊断工具

时间轴叠加围度曲线与每周饮食指标、事件标注，用「个体内对照」自动归因（用户自己的好周期 vs 停滞周期），并一键生成两周验证计划，形成行动闭环。

④ 诚实的产品设计

设置记录完整度门槛（周期内 ≥10 天才出归因报告）、冷启动 2–4 周基线期，所有结论标注「相关观察，仅供参考」——不做因果承诺、不做医疗建议。

竞品分析（驱动定位）

亲测薄荷健康（传统头部：大食物库 + 内容电商）与小卡健康（AI 新锐：拍照识别 + AI 搭子），梳理用户评价与版本迭代，输出功能对比矩阵与定位图，得出差异化结论：不做大食物库、不卷 AI 陪伴，专注「记录颗粒度 → 精准估算」与「围度/体型诊断」。

鼠钱 —— 萌宠陪伴式记账 App

鼠钱是一款以「仓鼠宠物养成」为核心创意的智能记账 App。针对传统记账工具「下载即流失、记账难坚持」的痛点，我完成了从用户调研、需求分析到原型设计、UI 视觉落地的完整流程。

🎨 UI 设计展示
详情▾
创意机制：萌宠记账激励闭环

用户注册时选择一只仓鼠作为记账伙伴，每次记账可获得宠物粮食，喂养仓鼠升级、解锁成就徽章与个性皮肤；仓鼠的情绪还与消费健康度实时联动——预算合理时开心，超支时焦虑。通过「记账 → 喂养 → 陪伴 → 坚持记账」的正向闭环，把枯燥的记账变成有温度、有反馈的养成体验。该机制经 KANO 模型验证，Better 系数 55.56%，为所有功能中最高，是产品的核心差异化亮点。

UI 设计能力

使用 Figma 完成 31 页高保真设计稿，视觉风格温暖治愈：奶油黄主色调、橙色渐变按钮、白色大圆角卡片，仓鼠 IP 贯穿登录、记账、数据分析、个人中心等全部页面，在保证信息层级清晰的同时，用情感化设计降低了理财工具的距离感。
